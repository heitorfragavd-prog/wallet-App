## Índices Críticos ⭐

### Para Edge Function (Processamento de Lembretes)
1. **idx_lembretes_manutencao_pendentes** (Parcial, Composto)
   - Query: Buscar lembretes pendentes para processar
   - Impacto: CRÍTICO - usado pelo job diário
   - Benefício: 10-100x mais rápido que scan completo

2. **idx_webhooks_manutencao_ativo_only** (Parcial)
   - Query: Buscar webhooks ativos para enviar
   - Impacto: CRÍTICO - usado pelo job diário
   - Benefício: Índice muito menor, lookups instantâneos

### Para Interface do Usuário
1. **idx_planos_manutencao_veiculo_ativo** (Parcial, Composto)
   - Query: Listar planos ativos de um veículo
   - Impacto: ALTO - usado em toda visualização de veículo
   - Benefício: Resposta instantânea na UI

2. **idx_lembretes_manutencao_veiculo_data** (Composto)
   - Query: Listar lembretes de um veículo ordenados por data
   - Impacto: ALTO - usado em toda visualização de veículo
   - Benefício: Ordenação eficiente sem sort adicional

### Para Admin Dashboard
1. **idx_logs_webhooks_manutencao_webhook_date** (Composto)
   - Query: Histórico de logs de um webhook
   - Impacto: MÉDIO - usado no painel admin
   - Benefício: Paginação eficiente de logs

2. **idx_logs_webhooks_manutencao_falhas** (Parcial)
   - Query: Análise de falhas HTTP
   - Impacto: MÉDIO - usado para troubleshooting
   - Benefício: Identificação rápida de problemas

## Queries Otimizadas

### 1. Buscar Planos Ativos de um Veículo
```sql
SELECT * FROM planos_manutencao_veiculo 
WHERE veiculo_id = ? AND ativo = true;
```
**Índice usado**: `idx_planos_manutencao_veiculo_ativo`

### 2. Processar Lembretes Pendentes (Edge Function)
```sql
SELECT * FROM lembretes_manutencao 
WHERE status = 'pendente' 
AND data_prevista <= CURRENT_DATE + INTERVAL '7 days';
```
**Índice usado**: `idx_lembretes_manutencao_pendentes`

### 3. Buscar Webhooks Ativos (Edge Function)
```sql
SELECT * FROM webhooks_manutencao WHERE ativo = true;
```
**Índice usado**: `idx_webhooks_manutencao_ativo_only`

### 4. Listar Lembretes de um Veículo
```sql
SELECT * FROM lembretes_manutencao 
WHERE veiculo_id = ? 
ORDER BY data_prevista DESC;
```
**Índice usado**: `idx_lembretes_manutencao_veiculo_data`

### 5. Analisar Falhas de Webhook
```sql
SELECT * FROM logs_webhooks_manutencao 
WHERE status_code >= 400 
ORDER BY created_at DESC;
```
**Índice usado**: `idx_logs_webhooks_manutencao_falhas`
