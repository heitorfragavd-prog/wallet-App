# Product Overview

Wallet is a personal and business financial management platform built in Portuguese (Brazilian). It provides intelligent financial consulting with WhatsApp integration.

## Core Features

- **Financial Management**: Income (receitas), expenses (despesas), transactions, debts (dívidas), and financial goals (metas)
- **Dashboard**: Real-time financial overview with charts and summaries
- **Categories**: Customizable transaction categorization
- **Vehicle Management**: Track vehicles, mileage, and maintenance schedules
- **Shopping Lists**: Market/grocery list management (mercado)
- **AI Integration**: Intelligent financial insights and analysis
- **Reports**: Detailed financial reports and analytics
- **Admin Panel**: User management, plans, subscriptions, and audit logs

## User Roles

- **User**: Standard access to personal financial features
- **Admin**: Full access including admin dashboard, user management, and system settings

## Target Audience

Brazilian users seeking simplified personal finance management with WhatsApp-based financial consulting.
